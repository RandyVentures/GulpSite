# Gulp Website

Public GitHub Pages site for Gulp.

## Overview

Gulp helps people turn hydration into a simple accountability habit by connecting water goals with selected app gates.

## Stack

- Static HTML/CSS
- GitHub Pages hosting
- Pages URL: `https://randyventures.github.io/GulpSite/`

## Project Structure

- `index.html` - landing and support page
- `privacy/index.html` - privacy policy
- `terms/index.html` - terms of use
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## Local Preview

Open `index.html` in a browser, or run any static file server from this directory.

## Deployment

Deploys from the `main` branch via GitHub Pages.
